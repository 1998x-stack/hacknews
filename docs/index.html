HackNews

Scheduled Hacker News digests, by email.

A production-grade pipeline that turns Hacker News metadata into clean, timely digests.

What it does

Every scheduled run fetches the latest Hacker News stories from the HN API, applies per-job selection rules, builds a compact digest, and sends it over SMTP — with structured logs, ops alerts, and a health signal when things go wrong.

  • Config-driven jobs with cron schedules and custom selection rules
  • Selection by score, comment count, age, and keywords
  • Structured JSON logs and a last-success / readiness probe
  • Runs as a container or a one-shot CI job

Quick look

hacknews doctor
hacknews run morning_digest
hacknews readiness
